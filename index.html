Quick Start

A short guide to start using Undergrain. You can reopen this from the ? button.

  1. 1. Load an audio file
    Click on FILE in the right panel and choose an audio file (WAV, MP3, etc.).
  2. 2. Select the region to granulate
    In the waveform at the top, drag with the mouse to select the part of the file you want to granulate.
  3. 3. Assign the sound to a pad
    Switch the XY mode to Pads, then click on a pad in the grid to assign the current selection and parameters.
  4. 4. Explore the topographic space
    Move the cursor on the big XY pad (or use the arrow keys) to explore variations of the sound in the topographic space.

Pads remember their settings when RECALL is ON, and you can use MIDI learn to control parameters from a controller.
